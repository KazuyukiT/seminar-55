3 Pythonの基礎

3.1 この章の目標と進め方

配布ファイル：演習ノートブック／解答ノートブック／PDF版。

Pythonは、計算やデータ処理の手順を文章のようなコードで書く言語です。この章では、架空の5人の学習時間を使い、集計して説明するところまで進みます。プログラミングの経験は必要ありません。

  • 値に名前を付け、数値と文字列を区別する。
  • リストと辞書で複数のデータを扱う。
  • 条件分岐・繰り返し・関数を組み合わせる。
  • エラーを読み、上から再実行できるノートブックを作る。

授業全15回・サブゼミ全10回のうち、授業2回（各90分を仮定）＋サブゼミ1回（60分）を使う案です。授業時間に合わせて途中の演習を宿題にできます。

回 内容 配分の目安
授業A 実行環境・計算・変数・リスト 準備15分、説明と実行45分、演習20分、振り返り10分
授業B 条件分岐・繰り返し・辞書・関数 復習10分、説明と実行55分、演習20分、振り返り5分
サブゼミ エラー修正・総合課題・相互確認 修正15分、課題30分、確認15分

各例は「結果を予想する → 実行する → 数値を一つ変える → 違いを説明する」の順で進めてください。解答例は章末にまとめています。

3.2 準備：ノートブックを開く

ノートブックは、説明文・コード・実行結果を一緒に保存するファイルです。拡張子は .ipynb です。

この章では、インストール済みの uvとVS Code を使い、自分のPCでPythonを実行します。uvはPythonとパッケージを管理する道具です。初回の環境準備にはネット接続が必要です。

3.2.1 uvで授業用の環境を作る

Windowsでは、uvをインストールしたWSLのLinux環境を使います。 VS Code本体はWindows側に置き、Microsoftの WSL拡張（ms-vscode-remote.remote-wsl）をインストールしてください。Macの人は通常のターミナルを使い、WSLの操作を省略します。

Windows TerminalでUbuntuなど、uvを入れたディストリビューションのタブを開きます。PowerShellから入る場合は wsl を実行します。複数ある場合は wsl -l -v で名前を確認し、wsl -d Ubuntu のように対象を指定します（Ubuntu は自分の名前に置き換えます）。以降のuvコマンドは WSL内のターミナル で実行します。

cd ~
uname -s
uv --version

WSLでは uname -s が Linux、Macでは Darwin を表示します。uv --version でバージョンが表示されることを確認します。WSLの ~ はLinux側のホーム（通常 /home/ユーザー名）です。この授業のフォルダはここに作ります。Windowsの C: ドライブ側にある既存の .venv は流用しません。

続けて以下を1行ずつ実行します。Pythonのセルではなく、ターミナルに入力します。

uv init --python 3.12 python-basics
cd python-basics
uv add --dev ipykernel
uv run python --version
code .

新しい python-basics フォルダを作り、Python 3.12を指定します。必要ならuvがPythonを取得します。ipykernel はノートブックからPythonを実行するためのパッケージです。最後の . は現在のフォルダを意味します。

WSLから code . を実行すると、Windows側のVS CodeがWSLに接続して開きます。初回はVS Code Serverの準備を待ち、左下に WSL: Ubuntu など接続先の表示 があることを確認します。code が使えない場合は、Windows側のVS CodeでF1を押し、WSL: Connect to WSL using Distro からuvを入れた環境を選び、そのウィンドウでLinux側の python-basics フォルダを開きます。Macの場合は通常の「フォルダーを開く」で構いません。

同名のフォルダがある場合は内容を確認してください。既にuvで初期化済みなら uv init は繰り返さず、そのフォルダへ移動して残りの手順を行います。

ファイル・フォルダ 役割
.venv/ 授業用のPython環境。他の作業とパッケージを分ける
pyproject.toml プロジェクトと必要なパッケージの設定
uv.lock 使用するパッケージのバージョンの記録
.python-version Pythonのバージョン指定

2回目以降は同じフォルダを開きます。別のPCで設定ファイルを受け取った場合は、そのフォルダで uv sync を実行して環境を準備できます。.venv 自体をコピーする必要はありません。

3.2.2 VS Codeでカーネルを選ぶ

  1. WSL接続中のVS Codeで、Microsoft提供の Python（ms-python.python）と Jupyter（ms-toolsai.jupyter）を確認します。「WSL: Ubuntuにインストール」などが表示されたら押し、WSL側で利用できる状態にします。Windows側だけへの導入では足りない場合があります。Macでは通常どおり導入します。
  2. 演習ノートブックをダウンロードします。
  3. 作成した python-basics フォルダに保存します。Windowsでダウンロードした場合は、WSLの作業フォルダで explorer.exe . を実行し、開いたエクスプローラーに .ipynb をコピーします。その後、WSL接続中のVS Codeのファイル一覧から開きます。提出時もこの方法で保存済みファイルを取り出せます。
  4. 右上の「カーネルの選択」から、必要なら「別のカーネルを選択」→「Python環境」を開き、このフォルダの .venv を選びます。
  5. WSLでもMacでも .venv/bin/python を選びます。WSLでは /home/ユーザー名/python-basics/.venv/bin/python のようなパスが目印です。Windows側の python.exe ではありません。

カーネルはセルを実行するプログラムです。ターミナルで仮想環境を有効化する操作は、この手順では不要です。最初に新しいコードセルで次を実行し、パスに python-basics と .venv が含まれることを確認します。

import sys
print(sys.executable)

パスはPCごとに異なります。次に挨拶のセルを選び、左の実行ボタン、またはShift+Enterで実行します。

「セル」はノートブックの一つの入力枠です。コードセルにPython、テキストセルにMarkdownを書きます。教材Webページ上のコードは、その場では実行されません。

print("こんにちは、Python")

結果： こんにちは、Python と表示されます。print() は括弧内の値を表示する関数です。引用符は文字列の境界を表します。

ノート実行順序が大切

上のセルで作った変数を下のセルで使います。画面の並びではなく、実際に実行した順番で状態が変わります。作業の最後はノートブック上部の「カーネルの再起動」を実行し、「すべて実行」で上から動くか確認します。再起動すると変数は消えますが、保存したコードは残ります。MacはCommand+S、WindowsはCtrl+Sで保存します。

3.2.3 環境がうまく動かないとき

  • .venv が候補に出ない： 左下にWSL接続先が表示され、Python・Jupyter拡張がWSL側に入り、Linux側の python-basics フォルダを開いているか確認します。必要ならそのWSLで code . を実行し直します。Macでは開いているフォルダを確認します。
  • uvが見つからない： PowerShellでなく、uvを導入したWSLのターミナルか確認します。別のディストリビューションに入っていないかも確認し、ターミナルを開き直します。
  • ipykernelがない： そのフォルダのターミナルで uv add --dev ipykernel を実行し、カーネルを選び直します。
  • 違うPythonが動く： セルの sys.executable と、ターミナルの uv run python -c "import sys; print(sys.executable)" のパスを比べ、同じ .venv を選択します。
  • 文字として表示される： セルの種類をMarkdownからコードに切り替えます。

公式資料：VS CodeのWSL接続、uvとVS Codeの連携、VS Codeのノートブック操作。

3.3 計算と変数

3.3.1 計算を表示する

print(1200 + 800)
print(1200 * 3)
print(7 / 2)
print(7 // 2)
print(7 % 2)
print(2 ** 3)

結果（上から）： 2000、3600、3.5、3、1、8。

* は掛け算、/ は割り算、// は商を小さい整数側へ丸める除算、% は余り、** は累乗です。掛け算・割り算は足し算より先に計算されます。順序を変えたいときは括弧を使います。

3.3.2 値に名前を付ける

price = 1200
quantity = 3
total = price * quantity
print(total)

結果： 3600。price などを変数と呼びます。= は「右側を計算し、左側の名前に結び付ける」という代入です。数学の等式とは意味が異なります。

quantity = 4
print(total)
total = price * quantity
print(total)

結果： 3600、4800。変数を変えても、過去に計算した値は自動更新されません。計算し直す必要があります。

変数名には study_hours のように意味の分かる英小文字とアンダースコアを使います。大文字・小文字は区別されます。print、sum、list のような組み込み機能の名前は変数名に使わないでください。

3.3.3 演習1：予算を計算する

1冊850円の本を3冊買い、送料が200円かかります。価格・冊数・送料をそれぞれ変数にして合計を求めてください。その後、冊数を4に変更して再計算します。結果が変わる理由を1文で説明してください。

3.4 数値・文字列・真偽値

型 例 用途
int 3 整数
float 2.5 小数を含む数値
str "ゼミ"、"3" 文字列
bool True、False 条件が成り立つか 
hours_text = "3"
print(hours_text + "2")
hours = int(hours_text)
print(hours + 2)
print(type(hours_text).__name__)

結果： 32、5、str。文字列の + は文字をつなぎます。int() は整数への変換、type() は型の確認です。小数の文字列 "2.5" を数値にしたいときは float() を使います。

name = "学生A"
hours = 2.5
print(f"{name}の学習時間は{hours}時間です")

結果： 学生Aの学習時間は2.5時間です。先頭に f を付けた文字列では、{} に変数や計算式を入れられます。

# から行末はコメントです。処理の目的や単位をメモできます。

weekly_hours = 6  # 単位は時間／週
print(weekly_hours >= 5)

結果： True。>= は「以上」の比較です。

3.4.1 演習2：文字を数値にする

minutes_text = "90" を整数に変換し、60で割って時間に直してください。f文字列を使って 学習時間は1.5時間です と表示します。

3.5 リスト：複数の値をまとめる

5人の1週間の学習時間を、リストにまとめます。角括弧 [] で囲み、値をコンマで区切ります。この章のデータはすべて架空です。

study_hours = [2, 5, 0, 3, 10]
print(study_hours[0])
print(study_hours[-1])
print(study_hours[1:3])
print(len(study_hours))

結果： 2、10、[5, 0]、5。位置を表す番号（インデックス）は0から始まります。-1 は最後、[1:3] は1番目から3番目の直前までです。len() は要素数を返します。

total_hours = sum(study_hours)
mean_hours = total_hours / len(study_hours)
print(total_hours)
print(mean_hours)
print(min(study_hours), max(study_hours))

結果： 20、4.0、0 10。sum() は合計、min() と max() は最小値・最大値です。平均は空のリストでは計算できません。

重要0と欠測を区別する

ここでの0は「学習時間が0時間という回答」です。「未回答」を0に置き換えると平均の意味が変わります。実際のデータ分析では、欠測をどう扱ったかを必ず記録します。

3.5.1 演習3：一つの値で平均はどう変わるか

study_hours を [2, 5, 0, 3, 20] に変えて平均を計算してください。最初の平均と比べ、平均だけで「典型的な学生」を説明する際の注意を1文で書きます。実験後は元の [2, 5, 0, 3, 10] に戻します。

3.6 条件分岐：条件で処理を変える

hours = 5
if hours >= 5:
    print("5時間以上")
else:
    print("5時間未満")

結果： 5時間以上。if の後ろに条件を書き、行末に : を付けます。条件が成り立つと、その下の字下げした処理が実行されます。else はそれ以外です。字下げは半角スペース4個にそろえます。

比較 意味
a == b 等しい
a != b 等しくない
a > b、a >= b より大きい、以上
a < b、a <= b より小さい、以下

代入の = と比較の == を区別してください。条件を組み合わせるときは and（両方）、or（少なくとも一方）を使います。

hours = 0
if hours == 0:
    print("0時間")
elif hours < 5:
    print("0時間より多く5時間未満")
else:
    print("5時間以上")

結果： 0時間。elif は追加の条件です。上から調べ、最初に成り立った枝だけを実行します。この例は0以上の時間を前提にしています。

3.6.1 演習4：境界を確かめる

最初の if の例を、hours が4、5、6の場合で試してください。条件を hours > 5 に変えると、どの場合だけ結果が変わりますか。

3.7 繰り返し：同じ処理を各データに行う

study_hours = [2, 5, 0, 3, 10]
for hours in study_hours:
    print(hours * 60)

結果（上から）： 120、300、0、180、600。for はリストから値を順に取り出して hours に代入し、字下げした処理を繰り返します。

3.7.1 条件に合う人数を数える

count = 0
for hours in study_hours:
    if hours >= 5:
        count = count + 1
print(count)

結果： 2。count = count + 1 は、現在の値に1を足して代入し直します。count の初期化はループの前、最後の表示はループの外です。実行前に、2、5、0、3、10を読んだ直後の count を紙に書いてみてください。

range(3) は0、1、2を順に生成します。決まった回数の繰り返しで使えます。

for i in range(3):
    print(i)

3.7.2 演習5：条件に合う値を集める

空のリスト selected = [] を用意し、5時間以上の値を selected.append(hours) で追加してください。append() は末尾に要素を追加する操作です。元データを変更せず、結果が [5, 10] になることを確認します。

3.8 辞書：項目名と値を対応させる

辞書は、項目名（キー）で値を取り出す仕組みです。リストの「何番目」と区別しましょう。

student = {"id": "A", "hours": 2}
print(student["id"])
print(student["hours"])

結果： A、2。辞書をリストに入れると、小さな表のように複数人の情報を扱えます。

students = [
    {"id": "A", "hours": 2},
    {"id": "B", "hours": 5},
    {"id": "C", "hours": 0},
]
for student in students:
    print(f"{student['id']}: {student['hours']}時間")

結果： A: 2時間、B: 5時間、C: 0時間。外側の二重引用符と内側の一重引用符を区別してください。大量の表データを扱うpandasは、この基礎の後で学びます。

3.9 関数：処理に名前を付ける

同じ計算を別の値でも使えるよう、関数にまとめます。

def to_minutes(hours):
    return hours * 60

result = to_minutes(2.5)
print(result)

結果： 150.0。def は関数の定義、hours は受け取る値の名前（引数）、return は返す値（戻り値）の指定です。定義しただけでは計算は実行されません。to_minutes(2.5) と呼び出すと動きます。

print() は表示、return は呼び出し元へ値を渡す操作です。返された値は次の計算に使えます。

print(to_minutes(1) + to_minutes(2))

結果： 180。関数内で return の代わりに print だけを使うと、呼び出しの戻り値は None（値がないことを表す値）になります。

3.9.1 演習6：割合を求める関数

percentage(part, whole) を定義し、part / whole * 100 を返してください。percentage(2, 5) が 40.0 になることを確認します。ここでは whole が正の数であることを前提にします。

3.10 エラーを読んで直す

エラーは、処理を進められなかった場所を知らせる情報です。まずメッセージの最後の行で種類を読み、示された行とその前後を確認します。

エラー 典型的な原因 最初に確かめること
NameError 変数が未定義 スペル、定義セルの実行
TypeError 型の組み合わせが不適切 文字列と数値の区別
SyntaxError 文法が不正 :、括弧、引用符
IndentationError 字下げが不正 ブロックを半角4スペースにそろえる
IndexError リストの範囲外 5要素なら位置は0〜4
KeyError 辞書にキーがない キーの名前
ZeroDivisionError 0で割った 分母、空のリスト

修正問題： 以下は意図的に誤ったコードです。単独のセルで試し、理由を説明して直します。提出時には修正済みにしてください。

print("3" + 2)

もう一問： study_hours = [2, 5, 0, 3, 10] に対して study_hours[5] を使うとどうなるでしょう。最後の値を取り出す方法を二つ考えてください。

ヒントAIに相談するとき

まず結果を予想し、自分で1回実行します。相談では「期待した結果」「実際の結果」「短いコード」を伝え、「答え全部ではなく、原因とヒントを説明して」と依頼してみましょう。修正後は自分で再実行し、変更理由を説明します。実在の学生情報や認証情報は入力しません。

3.11 総合課題：学習時間の集計メモ

次のデータを新しいセルに定義してください。これは小規模な架空データであり、実際の学生集団について推論するための標本ではありません。

survey_hours = [2, 5, 0, 3, 10]
  1. 人数、合計、平均を計算し、単位とともに表示します。
  2. 5時間以上の人数と割合（%）を求めます。人数は for と if で数え、割合は演習6の関数を使います。
  3. Python標準ライブラリの statistics から median を読み込み、中央値を求めます。標準ライブラリはPythonに付属する道具で、追加インストールは不要です。
  4. 平均と中央値の違い、0時間の扱い、データの限界をMarkdownセルに3〜5文で説明します。
  5. VS Codeでカーネルを再起動し、上からすべて実行して同じ結果になることを確認します。

中央値の計算方法：

from statistics import median
print(median(survey_hours))

確認値： 5人、20時間、平均4.0時間、5時間以上2人、40.0%、中央値3時間。

提出するものは、コード・結果・考察を含む .ipynb ファイルです。VS Codeで保存し、作業フォルダ内のファイルを提出します。.venv フォルダは提出しません。環境確認セルの出力にPCのユーザー名などが含まれる場合は、その出力だけ消して保存してください。AIを利用した場合は、何を相談し、何を自分で確認したかを末尾に記録します。

確認観点 達成の目安
再現性 再起動後も上から実行できる
計算 全確認値が一致し、単位がある
理解 条件と繰り返しの動きを説明できる
解釈 0と欠測を区別し、過度な一般化をしない

3.12 解答例と振り返り

先に自分のコードを保存してから比較してください。同じ結果になる別の書き方も正解です。

3.12.1 演習1・2

book_price = 850
books = 3
shipping = 200
print(book_price * books + shipping)
books = 4
print(book_price * books + shipping)

minutes_text = "90"
hours = int(minutes_text) / 60
print(f"学習時間は{hours}時間です")

結果は2750円、3600円、1.5時間です。冊数を変えた後に合計を再計算しています。

3.12.2 演習3・4

changed_hours = [2, 5, 0, 3, 20]
print(sum(changed_hours) / len(changed_hours))

平均は6.0時間です。一つの大きな値で平均が上がるため、分布や中央値も確認します。演習4で結果が変わるのは5時間のときです。>= は5を含み、> は含みません。

3.12.3 演習5・6

study_hours = [2, 5, 0, 3, 10]
selected = []
for hours in study_hours:
    if hours >= 5:
        selected.append(hours)
print(selected)

def percentage(part, whole):
    return part / whole * 100

print(percentage(2, 5))

結果は [5, 10] と 40.0。修正問題は print(int("3") + 2) なら数値の5になります。文字の連結を意図するなら print("3" + "2") です。最後の要素は study_hours[4] または study_hours[-1] で取得できます。

3.12.4 総合課題の解答例

from statistics import median

def percentage(part, whole):
    return part / whole * 100

survey_hours = [2, 5, 0, 3, 10]
n = len(survey_hours)
total = sum(survey_hours)
count = 0
for hours in survey_hours:
    if hours >= 5:
        count = count + 1

print(f"人数: {n}人")
print(f"合計: {total}時間")
print(f"平均: {total / n:.1f}時間")
print(f"5時間以上: {count}人")
print(f"割合: {percentage(count, n):.1f}%")
print(f"中央値: {median(survey_hours)}時間")

:.1f は小数点以下を1桁にそろえて表示する指定です。このコードは空でない数値リストを前提にしています。

考察例：平均は4.0時間、中央値は3時間である。10時間という値が平均を高くしている。0時間は有効な回答として含めた。この架空の5人の結果を、大学生全体の傾向と考えることはできない。
